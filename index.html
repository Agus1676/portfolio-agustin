Plataforma de comercio electrónico de alta gama con simulaciones físicas, osciladores de sonido y ruleta de premios.

Una experiencia web ultra-interactiva pensada para entusiastas de teclados mecánicos. Permite "probar" la acústica de diferentes interruptores sintéticamente e interactuar con mecánicas de juego en el cliente.

Resumatch — Analizador de CV & ATS con Inteligencia Artificial

Aplicación web Full-Stack que compara currículums en formato PDF contra descripciones de puestos, calculando un score de compatibilidad y sugiriendo mejoras precisas.

Una solución diseñada para ayudar a los candidatos a superar los filtros automatizados (ATS) y optimizar sus currículums utilizando modelos generativos de IA.

  • Procesamiento Inteligente: Extracción de texto de archivos PDF en Python con `pypdf` y análisis semántico profundo usando la API de Gemini 2.5 Flash.
  • Feedback Detallado: Identificación precisa de palabras clave (keywords) faltantes y sugerencias estructuradas paso a paso para reescribir secciones del CV.
  • Reportes PDF de Alta Calidad: Generación y descarga automatizada del reporte de compatibilidad en formato A4 usando `jsPDF`.
  • Arquitectura CI/CD: Pipeline automatizado que integra el repositorio con Vercel (Frontend React) y Render (Backend FastAPI).
